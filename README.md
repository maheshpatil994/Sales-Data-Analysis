# 📊 Sales Data Analysis

A data analysis project using **Python and Power BI** to analyze sales data, identify business trends, and create an interactive dashboard for meaningful insights.

## 🎯 Project Objective

The main objective of this project is to analyze sales data and understand:

* Overall sales performance
* Top-performing products and categories
* State-wise sales performance
* Monthly sales trends
* Order volume
* Payment methods
* Category-wise performance across states
* High-performing and low-performing areas

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **Matplotlib**
* **Jupyter Notebook**
* **Power BI**
* **CSV**

## 🔄 Project Workflow

1. **Data Understanding**

   * Loaded and explored the sales dataset.
   * Checked columns, data types, and basic information.

2. **Data Cleaning & Preparation**

   * Prepared the dataset for analysis.
   * Created a cleaned version of the dataset.

3. **Data Analysis**

   * Analyzed sales performance.
   * Identified top products, categories, and states.
   * Studied monthly and regional trends.

4. **Data Visualization**

   * Created visualizations using Python.
   * Used charts to understand sales patterns and business performance.

5. **Power BI Dashboard**

   * Created an interactive dashboard using Power BI.
   * Presented sales trends, product performance, state-wise sales, payment methods, and other key metrics.

## 📈 Key Insights

The analysis helps identify:

* Top-performing products based on sales.
* States with higher sales performance.
* Monthly sales trends.
* Category-wise sales performance.
* Order volume and payment method distribution.
* Regional differences in product and sales performance.
